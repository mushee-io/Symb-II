# Symb-II Windows 0.1.0 — UNSIGNED BETA

**For controlled testing. This is not an independently tested or signed public financial application.**

- Windows 10/11 x64 NSIS installer: `Symb-II-Setup-0.1.0-x64.exe`
- The SHA256SUMS.txt file contains the exact installer checksum. Verify it before installing.
- Installer is unsigned. Do not disable Windows security controls to bypass warnings from untrusted files.
- Symb-II Desktop loads the official HTTPS workspace and requires a network connection.
- Nado order submission, Tydro deposits/borrowing and autonomous trading remain **disabled**.
- Real-device WalletConnect QR pairing, signed release, external audit, installer SmartScreen checks and updates are **not yet accepted**.

This GitHub Releases asset is the permanent download host for the Symb-II Windows beta. Future binary revisions should use new versioned release tags; do not replace an existing installer silently.
